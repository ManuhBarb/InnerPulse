# InnerPulse

O InnerPulse é um projeto desenvolvido como uma possibilidade de ferramenta para a telemedicina, buscando facilitar o acompanhamento pessoal da saúde e ampliar o acesso a recursos de cuidado, especialmente para moradores de zonas rurais, pessoas com mobilidade reduzida e indivíduos que apresentam poucos sintomas. O sistema foi desenvolvido utilizando HTML e CSS para a estrutura e estilização da interface, JavaScript para a implementação da lógica e interatividade, e Django e PostGreSQL para o desenvolvimento das demais funcionalidades.
